Chain-truth oracle for one TOB bucket, reading over RPC rather than the mirror (production cert readers are mirror reads, so the tests need an independent source): find the bucket Field in the tob bag, decode its nodes in whichever layout the bucket’s on-chain value type names (bare submissions are lifted to the stamped form the mirror stores), and walk the LinkedTable in link order. Returns None when the bucket does not exist on-chain.

    private_key: &Ed25519PrivateKey,

Expand description

Publish the bytecode snapshot at snapshot_dir as a fresh package, driven by private_key. Mirrors the publish module but sources the modules from a checked-in bytecode snapshot instead of a source build.

Like the source-build path, the UpgradeCap is transferred to the sender and left there until hashi::finish_publish (the launch switch) hands it into on-chain custody — so the returned PublishOutput slots directly into the normal genesis/launch sequencing.

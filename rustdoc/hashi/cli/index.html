complete_step
Overwrite the current status line with a success message.
confirm
Ask the operator to confirm. Requires an explicit y; anything else is a decline. When stdin is not a terminal there is nobody to answer, so the command refuses to proceed instead of treating an empty read as consent, and points at --yes.
explain_tx_error
Attach a human explanation to a transaction failure when it is a Move abort (a clever #[error] constant with a hint, or the framework’s dynamic-field miss); other errors pass through unchanged. Every CLI path that finalizes or executes a transaction maps its error through this, so the operator never has to read a raw MoveAbort line first.
explorer_tx_url
DevXplorer deep-link for a transaction digest, or None when the RPC URL does not map to a network the explorer serves (e.g. localnet).
print_detail
Print a human-readable note or summary line. Notes always go to stderr: stdout carries only results (tables, JSON, a proposal id, a transaction digest, or the base64 unsigned transaction), so piping any command’s stdout into another tool never picks up progress chatter.
print_info
Print an info message
print_step
Print an in-progress status line (no newline) that can be overwritten.
print_success
Print a success message
print_tx_digest
Print a transaction digest with its explorer deep-link (when the network has one) so the result can be verified in a browser with one click.
print_tx_outcome
Render the result of a finalized transaction and return the execution response when one was produced (execute mode only). The serialized unsigned transaction is the only thing written to stdout; everything else is a note. sui_rpc_url is used to derive the explorer deep-link for the digest.
print_warning

run

run_launch
Run the launch command – send hashi::finish_publish (the launch switch): configure the deploy (chain id, guardian, overrides) and hand the package UpgradeCap into on-chain custody, which unlocks genesis. The initial committee forms from the validators fully registered at that moment.
run_publish
Run the publish command – build, publish, and initialise the Hashi package.
run_register
Run the register command – register a validator on-chain.

pub fn resolve_version_support(
    enabled: &BTreeSet<u64>,
    published: &PackageVersions,
    supported: &[u64],
) -> VersionSupport
Expand description

Resolve version support from the enabled set (governance), the published version map (on-chain package history), and this binary’s supported set.

The active version is max(enabled ∩ published ∩ supported). A version that is enabled but not yet published (governance can enable ahead of a deploy) is excluded, so the ABI is never switched on before the package is live.

Pure over its inputs for exhaustive unit testing; super::OnchainState wraps it against live state.

Module operator_rotate_kp_set 

Source
Expand description

operator rotate-kp-set: re-deal the ceremony key to a new KP set on a fresh ceremony-mode guardian. init operator-initializes it and pins the session the current KPs sign for; submit batches their submissions into one RotateKpSet, verifies what was dealt and waits for every new KP; wait resumes that wait.

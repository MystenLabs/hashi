Module withdrawals 

Source
Expand description

The proxy checks each withdrawal against its committed Sui transaction.

Why it exists: The enclave checks only the committee certificate on a withdrawal. A compromised committee can certify UTXOs that Move never committed. The guardian limiter bounds that loss, but it does not stop it.

How it works:

  1. Read the WithdrawalTransaction object whose id is the request wid.
  2. Require the object type from the Hashi package.
  3. Build the UTXOs from the object with TxUTXOs::from_withdrawal_txn. Nodes build their request with the same function.
  4. Forward the request only when its UTXOs are equal to those UTXOs.

Assumptions:

  • Move commits the object before the leader asks the guardian to sign.
  • The original Hashi package defines WithdrawalTransaction.
  • The wid log replay runs before this check. Thus the proxy can replay a signed withdrawal after Sui archives its object.
  • The enclave checks timestamp_secs, seq and the certificate. Sui does not store them.

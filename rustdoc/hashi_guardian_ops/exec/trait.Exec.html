fn output(&self, cmd: &Cmd) -> Result<Output>

Runs cmd to completion with its stdout captured and its stderr on the terminal, as $(...) does, unless the command captures stderr too.

fn run(&self, cmd: &Cmd) -> Result<bool>

Runs cmd on the terminal, as a plain command line in a script does, and returns whether it succeeded.

Source

fn exec(&self, cmd: &Cmd) -> Error

Replaces this process with cmd, as bash’s exec does. Returns only if that fails.

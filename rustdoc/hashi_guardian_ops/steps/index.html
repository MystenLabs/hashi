Module steps

One function per operator step. Each reads what it acts on fresh, checks it, asks before changing anything, acts, and checks the result.

Modules§

configs
The steps that write a slot’s configuration and hand it to the key provisioners: render and publish.
deploy
The guardian’s infrastructure: measure its build, deploy the enclave stack and roll the proxy.
inspect
The steps that change nothing: status, info, host and tunnel.
kp_keys
Collecting the key provisioners’ public keys from their upload bucket: download-kp-pubkeys.
rotate
Moving the guardian’s key to a fresh host in the stack’s other slot: arm a standby, proxy-update, switchover and teardown. Every step re-reads the stack, the hosts and the proxy, applies only a targeted plan of exactly the expected shape, and can run again to resume.
rotate_kp_set
Re-dealing the guardian’s key to a new set of key provisioners on a standby: rotate-kp-set init, submit the signers’ submissions, or wait for the new set to confirm.
session
A guardian session’s life, through hashi-guardian-init at the guardian’s commit: ceremony, new-session, provision and activate.

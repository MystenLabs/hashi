hashi_guardian_ops::steps

Module rotate 

Source
Expand description

Moving the guardian’s key to a fresh host in the stack’s other slot: arm a standby, proxy-update, switchover and teardown. Every step re-reads the stack, the hosts and the proxy, applies only a targeted plan of exactly the expected shape, and can run again to resume.

Functions§

arm
Creates a standby guardian host in slot, next to the serving one in the other slot.
proxy_update
Applies the proxy stack so the proxy follows the enclave stack’s slots.
switchover
Makes the slot’s provisioned standby the serving guardian: flips the active slot, points the proxy at it, stops the old guardian for good, and activates the new one. Each phase is decided from live state, so a rerun resumes where an earlier run stopped.
teardown
Destroys a standby slot’s host: the retired guardian after a switchover, or a standby that never served.
